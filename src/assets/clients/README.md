# クライアントロゴ

掲載可の企業は `src/consts.ts` の `CLIENTS` に定義済み。
ここにファイルを置き、`CLIENTS` の `file` にファイル名を書くと表示対象になる。

## 入稿ルール

- 形式: SVG を最優先。無い場合は背景透過のPNG（横幅600px以上）
- 色: 原則モノクロ版（`#231815` 相当）。カラー指定がある場合はカラー版
- 余白: ロゴ自体の余白は削り、viewBox/canvas を実データにぴったり合わせる
- ファイル名: 英小文字とハイフン（例: `clf-partners.svg`）

## 注意

掲載できるのは各社の許諾を得た10社のみ。
`CLIENTS` に無い企業を追加しないこと。
