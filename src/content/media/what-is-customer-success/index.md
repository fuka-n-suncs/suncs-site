カスタマーサクセス（CS）は、現代のビジネスにおいて欠かせない概念となりました。多くの企業がその必要性を理解し、導入を始めていますが、まだまだ十分に価値を発揮しきれていない企業がほとんど、というのが現状です。本記事では、カスタマーサクセスの基礎知識から、今の日本のCSの課題とその背景やあるべき姿について、代表の中村の個人的な見解を含め解説していきます。

カスタマーサクセスとしてすでに働いている人はもちろん、これから導入していきたいけど費用対効果が悪そうで導入に踏み切れていない経営者の方にもぜひ読んでいただけたら嬉しいです！

## 1. カスタマーサクセスとは

カスタマーサクセスとは、**自社の製品やサービスの活用を通じて顧客のビジネスにおける目標達成や成功の実現を支援することで顧客のビジネスの成功と自社の利益の最大化を目指す活動** と定義しています。

実際は、各会社によって、カスタマーサクセスとしてインサイドセールスのような役割を担っていたり、問い合わせ対応をしているオペレーターのことを指していたりと定義は様々だったりしますが、弊社では上記の定義をして、カスタマーサクセスの価値を売上などの経営視点での定量データでしっかりと可視化できるようにしています。

後ほど細かな業務内容や役割については解説していきますが、カスタマーサクセスを語る上で重要なキーワードは **「顧客のビジネスにおける成長」** と **「能動的支援」** です。

そういった活動の結果として **自社の売上の最大化や効率化** が期待できる部署がカスタマーサクセスです。

### 1.1. カスタマーサクセスが注目される歴史的背景

カスタマーサクセスが注目され始めた一番の背景は、サブスクリプションモデルの普及です。従来の売り切り型のビジネスモデルでは、一度売れれば成功とされてきたものが、サブスクリプションモデルでは **一人（一社）の顧客の継続的な利用** が重要視されます。そのため、カスタマーサクセスによるサポートを通じて、顧客が満足して継続利用してくれることが求められています。

<!-- 図版: 旧サイトの図（1899×839）。元データ入稿後に ![説明](./figure-1.png) で差し込む -->

とはいえ、多くの企業がまだカスタマーサクセスよりも営業に予算やリソースを多く投下しているのも事実です。確かに売上へのインパクトを考えると、新規顧客を獲得してくることで瞬間的な売上の伸びや、売上全体の底上げが期待できる一方、カスタマーサクセスの活動による売上のインパクトは中長期的にみていく必要があります。もちろん最終的な結論としてはどっちの方が重要という優劣はなく、どっちも重要なわけですが・・・無限に新規顧客を獲得し続けることができるでしょうか？どの業界も市況感からある程度の獲得予算は見えていると思います。さらには人材不足の観点からも営業活動の効率化や、既存顧客の育成が必要ということは言うまでもなく明らかになってきています。

### 1.2. カスタマーサクセスの役割と重要性

カスタマーサクセスと聞くと、よく顧客満足度の向上や解約防止といったことがゴールとされがちですが、それでや十分にカスタマーサクセスの役割が担えているとは言えません。単なる製品やサービスのサポートを超え、顧客がビジネスにおいて最高の結果を得るために必要な支援を能動的に提供していくことが求められます。その活動の成果を図る指標として顧客満足度や解約率というものが存在します。顧客の成功＝自社の成功と捉え、顧客の課題を理解し、必要な解決策を提供することが重要で、顧客満足度の向上は途中の経過地点での一指標にすぎないのです。

▼サポートとサクセスの違い

| | カスタマーサクセス | カスタマーサポート |
|---|---|---|
| 目的 | 顧客のビジネスを成功に導く | 顧客の不安や不満を解消する |
| アプローチ | 能動的 | 受動的 |
| KPI | 解約率／アップセル・クロスセル率／顧客満足度 など | サービスレベル達成率／問い合わせ対応回数／平均応答時間 など |

**自社の製品やサービスの活用を通じて顧客が達成したいビジネス目標** を理解し、そこを共に目指していくパートナーとなっていくことが、カスタマーサクセスとしての価値向上となり、自社の売り上げへの貢献にもつながっていくのです。

## 2. カスタマーサクセスを導入するメリット

ここまでは顧客視点でカスタマーサクセスについて話をしましたが、カスタマーサクセスを導入するメリットとして、どのようなことが挙げられるのかを考えていきます。

### 2.1. 顧客満足度の向上

先ほど、顧客満足度の向上はカスタマーサクセスの最終的なゴールではないと話をしましたが、カスタマーサクセスとしてはとても重要な指標です。もちろん製品やサービスの質が高ければ高いほど、顧客は勝手に満足感を感じてくれますが、顧客によっても成熟度や新しいものに対する耐性はさまざまです。そんな顧客に対して一定の満足感を得てもらうには顧客ごとの状況や課題を把握し、求められている適切なサポートを提供する必要があり、その役割を担うのがカスタマーサクセスです。

### 2.2. ビジネス成長への影響

顧客の満足度がとても高い状態の先にはどのようなビジネスインパクトがあるでしょうか？満足度が高いということは顧客はかなりの確率でその製品/サービスを使い続けます。つまり、LTV（ライフタイムバリュー/顧客生涯価値）の向上が期待できるのです。経営視点で考えてみると、満足度の高い顧客が安定して製品/サービスを使い続けてくれるということは、安定的に入ってくる売り上げが見込めるということです。これまでは売上＝営業の頑張り次第だったのが、カスタマーサクセスの活動によって、一定の未来の売上を確定的に予測することができるようになったことで経営計画も立てやすくなり、ビジネスをより安定的に展開していくことが可能になります。

### 2.3. 顧客との長期的な関係構築

この長期的な関係構築というのは、ただ使い続けてもらうことによる顧客との長期的な関係構築ではありません。定期的なコミュニケーションやアンケートなどを通じて顧客のリアルな声を収集し、より良い製品/サービスにしていく、追加の提案の機会を探していくための関係構築です。ここがカスタマーサクセスがあるべき最大のポイントと言っても良いかもしれません。

顧客が本音を言える関係性、追加の提案を受け入れてもらえる関係性を築いていくことは容易ではありません。顧客以上に顧客のことを考え、日々コミュニケーションをとることで、顧客の信頼を勝ち取ることができ、その結果が自社の売上や成長に繋がっていきます。もちろんカスタマーサクセスとしてのKPI（成果）を追っていくことは大切ですが、**いかに顧客に向き合えるか** がカスタマーサクセスが意識すべきことかもしれません！

## 3. カスタマーサクセスの業務内容

カスタマーサクセスの業務内容は、多岐にわたりますが、今回は前項までで紹介した内容に基づく代表的な4つの業務をご紹介します。

### 3.1. オンボーディング

オンボーディングは、新しい顧客が製品やサービスを十分に使いこなせるようになるための最初のステップです。製品やサービスによってもこの期間で行うべきことやどれくらいの期間を設けるかはさまざまですが、顧客の不安を解消し、製品やサービスを活用して業務を行っていく具体的なイメージを持ってもらうために必要なサポートを実施していきます。

特に、キックオフミーティングは製品やサービス問わず新規顧客に対して実施をしていくべき内容です。カスタマーサクセスとして初めて顧客と接点を持つ場であり、ここでいかに顧客との目線合わせができるかでその後の関係性や顧客のロイヤリティに大きく影響します。オンボーディングやキックオフについてはそれだけで一記事書けそうなので改めて詳しく解説します！

### 3.2. 顧客の課題解決と活用促進

オンボーディングが完了すると顧客は活用フェーズに入ります。課題解決と活用促進に関しては、特定のフェーズで行うというよりも、定期的な顧客とのコミュニケーションの中で課題を見つけ、解決策を提案し、更なる活用を促していく活動となります。ただ、この活動を能動的に行えている組織はまだ多くありません。オンボーディング完了後、一気に受け身姿勢で問い合わせが来ない限り連絡を取らない、顧客の声を拾っていく方針が決まり、久しぶりに連絡をしたら全然返ってこない。みたいな状況に陥っているカスタマーサクセスをたくさん見てきました。笑

オンボーディングだけでなく、長期的な視点でいつどのように顧客と接点をもっていくのかはあらかじめ設計しておくことが重要です。当然新規顧客の対応優先度は上がるので、あらかじめ既存顧客に対するアクションが明確になっていることで長期的な関係構築に必要なコミュニケーションが取れるようになっていきます。

### 3.3. 契約更新・解約防止

契約更新と解約防止は、いかに先回りしてサポートやアクションができたか、ということの指標になります。各顧客のLTVを向上させていくことが求められているカスタマーサクセスにとって、契約の終了、解約というのは十分に価値を提供しきれなかったということを意味します。顧客にとってなくてはならないものにしていくためのサービス改善や、顧客の不安や不満の解消、製品やサービスを活用したことによる成功体験など、日々のコミュニケーションを通じて実現できることなのです。

また、更新のタイミングで、これまでの利用状況や成果をレビューし、良かった点や改善点を話すことも重要です。そういったコミュニケーションから追加の提案チャンスも生まれていきます。

### 3.4. アップセル・クロスセル

アップセル・クロスセルはカスタマーサクセスにとっての営業活動です。THE MODELでも言われている通り、カスタマーサクセスは営業プロセスの一つと捉えるべきだと考えています。

既存顧客に対しての、契約ボリュームを上げるための提案（アップセル）や付随する他サービスの提案（クロスセル）というのは、新規の営業活動に比べると受注までにかかるコストや工数が圧倒的に下がります。また、日々のコミュニケーションから顧客の状況を把握しているため、提案のタイミングや提案内容を顧客の課題解決につながるようカスタマイズして行うことができるという点もアップセル・クロスセルの強みです。

## 4. カスタマーサクセスにおける指標とは

カスタマーサクセスにおける指標とは、顧客が成果や効果を実感し、長期的にサービスを利用し続けるために必要な数値やデータのことです。どの顧客がどれくらい満足しているか、どの部分に問題があるのか、カスタマーサクセスとして、顧客と自社の両面でどれくらい貢献できているかを定量的に把握することができ、適切な戦略を立てることが可能になります。

### 4.1. KPI一覧

カスタマーサクセスにおけるKPI（Key Performance Indicator）は、主に **顧客の健康状態や利用状況を評価するため** と **カスタマーサクセスとしての貢献度を可視化するため** に使用されます。

## 5. カスタマーサクセスのあるべき姿

カスタマーサクセスとは、単に顧客を満足させるだけでなく、顧客の成功を確実にするための取り組みだということは理解いただけたかと思います。そのようなカスタマーサクセスになるために必要なスキルやマインドセットについて最後にご紹介します。

### 5.1. 身につけておくべきマインドセット

どんな行動も自発的に行っていくにはその土台となるマインドセットが重要です。カスタマーサクセスとして身につけておきたいマインドセット3つを紹介します。

**顧客思考**

カスタマーサクセスにおいて最も重要なことは、顧客が何を目指し、何に悩み、何を求めているのかを深く理解しているということです。顧客以上に顧客のことを考え、顧客と向き合う時間をたくさん作ることで顧客思考を磨いていきましょう。

**プロアクティブな姿勢**

「顧客から問い合わせがあったら対応する」のではなく、さまざまな情報から顧客が壁にぶつかる前に、予測されるリスクを払拭するためには常に能動的に活動していく姿勢が重要です。顧客から連絡が来ていないから困っていないだろう、という思い込みで顧客を放置してしまうことがないよう注意しましょう！

**目的意識**

全ての行動には、なぜその行動を取るのか、取るべきなのかという目的があります。目的を意識している行動と意識していない行動ではその先の結果も大きく変わってきます。行動を取ることが目的ではなく、その行動の先に何を求めるのか、ということを意識して顧客に寄り添ったカスタマーサクセスを目指しましょう！

### 5.2. 必要なスキルと役割分担

カスタマーサクセスは、時には営業としての動きが求められたり、コンサルタントのような動きが求められたりと、突き詰めていくとかなり複雑で役割も曖昧になりがちです。今回は、新人カスタマーサクセスとして最低限身につけたいスキルを3つ紹介します。

**コミュニケーション能力**

顧客に伴走するカスタマーサクセスにとってコミュニケーション能力は必須スキルです。顧客が求めている情報を的確に伝える力、顧客の想いや潜在ニーズを引き出す力、顧客の協力を得るための関係構築など、顧客思考を意識しつつ、伝え方など、他のメンバーからのフィードバックを積極的にもらうようにしましょう！

**クリティカルシンキング**

顧客に寄り添うことは重要ですが、寄り添いすぎて御用聞きになってしまったり問題の本質や目的を見失ってはいけません。顧客の課題の裏にあるニーズと、本来の目的とを照らし合わせつつ、データによる根拠と、顧客思考をもって長期的な成功に向けた戦略を立て、顧客を導くことこそカスタマーサクセスの役割です。

**戦略的思考**

目の前の顧客の要望に短期的に応えることも必要ですが、カスタマーサクセスとしては顧客との関係を長期的に描き、総合的な顧客満足度の向上や継続率をアップさせることが重要です。ここまでに挙げてきたマインドセットやスキルは全て戦略的思考にも必要なものになります。スキルの掛け合わせで顧客を成功へ導きましょう！
